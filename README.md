# Avito AntiBot

Решение задачи классификации `cookie_id` по событиям внутри суточного окна.

## Структура

- `solution.ipynb` — полный воспроизводимый код;
- `submission.csv` — итоговые предсказания;
- `requirements.txt` — версии зависимостей;
- `.gitignore` — исключает исходные данные и служебные файлы.

## Подход

Для каждой cookie события агрегируются в одну строку признаков.
Используются временные и поведенческие статистики:

- число событий и длительность активности;
- интервалы между событиями;
- разнообразие объявлений, категорий, локаций и запросов;
- доли типов событий;
- platform/User-Agent;
- search_page;
- pointer_x/pointer_y;
- концентрация действий;
- возраст cookie;
- количество полных дубликатов событий.

Признаки строятся только по событиям:

`window_start_ts <= event_ts < window_end_ts`.

## Валидация

Так как test расположен позже train, используется временной holdout:
последние дни train используются как validation, а не случайный split.

Основная метрика — `Precision @ Recall >= 0.70`.

## Модель

Финальная модель — `CatBoostClassifier`.

Случайность зафиксирована:

`random_seed = 43`.

## Что пробовалось

- RandomForest baseline на двух простых агрегатах;
- CatBoost на расширенном наборе признаков;
- feature selection;
- альтернативные boosting-модели и ансамбли.

Финально оставлена более простая модель CatBoost на полном наборе агрегатов,
так как дополнительные усложнения не дали устойчивого выигрыша на временных срезах.

## Запуск

Рекомендуемая версия Python: **3.11**.

Структура данных:

```text
project/
├── solution.ipynb
├── requirements.txt
└── data/
    ├── train.csv
    ├── test.csv
    └── events.csv.gz
```

Допускается `events.csv` вместо `events.csv.gz`.

Установка:

```bash
pip install -r requirements.txt
```

После этого открыть `solution.ipynb` и выполнить **Run All Cells**.
Последняя ячейка создаст `submission.csv`.
